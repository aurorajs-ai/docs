## `catalyst pipeline`

Generate a deploy workflow and its supporting files from templates (interactive).

```
USAGE
  $ catalyst pipeline [-f]

FLAGS
  -f, --force  Overwrite existing files of the set

DESCRIPTION
  Generate a deploy workflow and its supporting files from templates (interactive).

EXAMPLES
  $ catalyst pipeline

  $ catalyst pipeline --force
```
